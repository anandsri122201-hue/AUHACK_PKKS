Try to break it

These are the questions most likely to make an AI system guess: serial numbers one past the end of a range, withdrawn proposals, aircraft that aren't in the data, a model paired with the wrong manufacturer. Run them, then type your own on the first tab.

How an answer is made

The language model never writes the answer. Code decides applicability, and every sentence you read is copied from the documents.

  1. Read the questionRules pick out manufacturer, model, serial number and record, docket or AD numbers. If Claude is switched on, it may fill gaps, but only with words that appear in your question.
  2. Stop if it can't be answeredUnknown records, manufacturers or models outside the corpus, a model paired with the wrong manufacturer, or a model shared by several manufacturers all stop here with the reason.
  3. Check applicability in codeEach document's applicability paragraph is parsed into models, serial ranges, exclusions and conditions. The tag is the result of those checks, and each check shows its sentence.
  4. Follow the revision chainIf a docket has several records, older ones are marked outdated. If the latest one is a withdrawal, earlier proposals are marked withdrawn too.
  5. Quote, don't paraphraseAnswers are sentences copied from the corpus with record, docket, Federal Register page and section. Claude can only choose which sentences to show.
